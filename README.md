# Расписание ФЗО РГАТУ

Лёгкое неофициальное приложение для ФЗО РГАТУ, сделанное студентом 1 курса для студентов. Визуально оно опирается на университетскую сине-красную айдентику, но не выдаёт себя за официальный сервис. При первом запуске выбирается группа; дальше сразу открывается её расписание. В разделе расписания есть вкладки «Установочная сессия» и «Консультации», просмотр по дням, время звонков, текущая/ближайшая пара, подписи совместных групп, поиск предметов и преподавателей, смена группы и светлое/тёмное оформление.

Опубликовано: https://rgatu-lite.ivan-s-2001.workers.dev/

## Данные

Загружена осенняя установочная сессия заочников 2026/27 из присланного файла от 05.10.2026: 90 групп и подгрупп, 3 178 заполненных ячеек, 1 464 уникальных занятий. Общие занятия связаны с соответствующими группами. Очные группы из сводных листов преподавателей/аудиторий не включены: эти листы не являются расписанием данной заочной сессии.

Отдельно добавлен архив графика консультаций ФЗО от 03.04.2026: 70 групп и 265 событий. Он не смешивается с занятиями установочной сессии и открывается соседней вкладкой.\n\nВремя звонков предоставлено пользователем отдельно: два графика для понедельника–пятницы и субботы–воскресенья, московское время. Текущая и ближайшая пары вычисляются по реальному времени, с учётом перерывов. Под совместными занятиями показаны все остальные группы из импортированных связей. Прошедшая сессия обозначается явно, без выдачи сентябрьских занятий за сегодняшние.

`data/schedule-full.json` содержит исходный текст и ссылки на листы и ячейки. `public/schedule.json` содержит компактные данные для приложения. Excel не изменялся.

## Запуск и обновление

Приложение написано на HTML, CSS и JavaScript без фреймворков, сторонних шрифтов и внешних сервисов. Группа и тема сохраняются на устройстве. Сервер не хранит профили студентов. Для PWA все файлы и расписание сохраняются после первого открытия; Android включает их в APK и открывается без интернета с первого запуска.

```bash
python3 scripts/serve.py
python3 scripts/import_schedule.py /path/to/schedule.xlsx
python3 scripts/generate_assets.py
python3 scripts/build_android.py --sdk /path/to/android-sdk
python3 scripts/build_worker.py
node scripts/test_offline.cjs
```

Для импорта нужны Python и `openpyxl`, для иконок — Pillow. Android собирается Java 17 и Android SDK (build-tools 34.0.0, platform android-35), без Gradle. Минимальная версия телефона — Android 8.0. Нужно только разрешение на интернет. Встроенный экран обновляет расписание с `/api/schedule`, при недоступной сети сохраняет работоспособность.

Ключ подписи хранится приватно в `android/signing/` и в ранее выданном приватном архиве версии 1.0.0. Этот каталог исключён из Git и веб-публикации. Для совместимых обновлений нужно использовать именно этот ключ; не создавать новый. В репозиторий попадает только уже подписанный APK, а не ключ или пароль.

## GitHub Pages и Android-обновления

Исходники: `ivan-s-2001/rgatu-schedule`, ветка `main`. Старое содержимое заменено этим проектом отдельным коммитом, с сохранением истории.

`docs/` — отдельная страница скачивания для Android и открытия на iPhone; `docs/download/RgatuLite.apk` — актуальный подписанный файл. `docs/version.json` описывает его версию и контрольную сумму.

Источник публикации в Settings → Pages — **GitHub Actions**. GitHub Pages включён. Страница скачивания публикуется по адресу https://ivan-s-2001.github.io/rgatu-schedule/ из `docs/`. На момент выпуска репозиторий публичный; ключ подписи и пароль в него не включены.

Workflow `pages.yml` публикует `docs/` при изменении `main`. `release.yml` создаёт Android-релиз из уже подписанного APK. Чтобы выпустить новую версию: увеличить `versionCode`/`versionName`, сохранить ключ подписи, собрать APK, заменить `docs/download/RgatuLite.apk`, обновить `docs/version.json`, страницу и заметки релиза. При установке поверх версии 1.0.0 группа сохраняется.

## Публикация

`dist/worker.mjs` создаётся из проверенных файлов и подписанного APK. Его нужно загрузить в Cloudflare Worker `rgatu-lite` и включить адрес workers.dev. Статические файлы сжаты заранее; сервер отдаёт сжатые байты с `encodeBody: manual`, чтобы избежать повторного сжатия. APK доступен по `/download/android`; копия страницы скачивания — по `/install/`. Ни база данных, ни платные сервисы не используются.

## Проверка

В опубликованной версии через браузер проверены первый выбор группы, повторное открытие с сохранённой группой, реальные предмет/преподаватель/аудитория, поиск и пустой поиск, переключение экранов. Отдельный тест проверяет сохранение файлов и расписания для открытия без сети. APK собран и проверен `apksigner`; запуск на физическом Android-устройстве в этой среде не выполнялся.

`scripts/test_app.cjs` содержит расширенную проверку с Playwright для окружения, где установлен Chromium; в текущей среде этот браузер недоступен, поэтому проверка интерфейса выполнена в доступном облачном браузере.

## Просмотр и обновления

Основной экран показывает один день. Дату можно менять стрелками, нажатием в полосе недели и смахиванием по карточкам. Календарь месяца открывается по заголовку даты. Поиск предмета, преподавателя и аудитории открывается по кнопке поиска. Нижнее меню: расписание, звонки, моя группа.

Начиная с Android 1.2.0 приложение проверяет обновления на старте (не чаще одного раза за 6 часов), скачивает APK в свой приватный кэш и сверяет размер, SHA-256, пакет, номер версии и сертификат подписи. Установку всегда подтверждает системный установщик Android. При первом обновлении нужно разрешить установку из РГАТУ Пары; затем приложение возвращается к установке. Ключ подписи прежний, группа сохраняется. `UpdateProvider` выдаёт доступ только к одному проверенному APK.
