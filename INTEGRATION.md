# Интеграция расписания в системы университета

Проект можно использовать не только как самостоятельный PWA/APK, но и как read-only источник расписания для официального сайта, личного кабинета, мобильного приложения или внутреннего сервиса.

## Слои

- `public/institution.json` — профиль университета: идентификаторы, официальные ссылки, брендинг, часовой пояс, звонки и параметры интеграции.
- импорт Excel — текущий source adapter РГАТУ; при появлении официального API/БД меняется только адаптер.
- `/api/v1/*` — стабильный внешний контракт.
- `/api/schedule` — legacy endpoint для нынешнего PWA/APK.
- `?embed=1` — режим без самостоятельной оболочки для встраивания.
- `?group=<код>` — внешний ЛК может сразу открыть расписание нужной группы.

## API v1

- `GET /api/v1/meta`
- `GET /api/v1/groups`
- `GET /api/v1/teachers`
- `GET /api/v1/schedule?group=ЗВС-26&date=2026-10-08`
- `GET /api/v1/schedule?teacher=Фоменко%20С.А.`
- `GET /api/v1/openapi.json`

Публичные endpoint'ы read-only и поддерживают CORS. Ошибки имеют форму `{"error":{"code":"...","message":"..."}}`.

## Встраивание

```html
<iframe
  src="https://rgatu-lite.ivan-s-2001.workers.dev/?embed=1&group=ЗВС-26#day"
  title="Расписание ФЗО">
</iframe>
```

Worker разрешает встраивание с `rsatu.ru` и его поддоменов.

## Если университет даст официальный доступ

Клиент и API-контракт менять не нужно. Добавляется новый адаптер источника (REST/SOAP/1С/БД), а нормализованный формат остаётся тем же. Для приватных данных следующий слой — SSO/OIDC университета и разграничение доступа; публичное расписание может оставаться без авторизации.
