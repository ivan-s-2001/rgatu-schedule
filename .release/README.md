# .release

Здесь лежат только архивные данные, использованные для воспроизводимого восстановления уже подписанных APK без публикации приватного ключа.

- `v1.4.6/` и `v1.4.7/` — бинарные zstd-patch-фрагменты для соответствующих исторических релизов.
- Они **не являются текущим способом версионирования**.
- Текущая версия определяется только корневым `version.json`.
- Публичная история APK хранится в `releases.json` и `RELEASES.md`.
